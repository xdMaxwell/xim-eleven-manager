The current retro rewrite is still too empty and the retro football feeling is not strong enough.

Main problem:
It still feels like a sparse web interface with retro styling, not a real retro football game menu.

New goal:
Rebuild the UI into a denser, more playful, more maximalist retro arcade football interface.

Important:
Do not just polish.
Increase visual density and scene complexity.

We want:
- PS1 / PS2 football game menu energy
- anime football arcade energy
- fake 3D / low-poly scene objects
- dense HUD
- decorative game UI
- more objects on screen
- more football atmosphere
- less empty space

We do NOT want:
- empty gradient backgrounds
- tiny isolated panels
- minimalist retro
- thin web UI
- sparse layout
- “web app with retro skin”

VISUAL DENSITY RULE:
For each main screen above the fold, include:
1. one large hero object
2. at least 2 to 4 support widgets/panels
3. a ticker or active info strip
4. decorative background elements
5. a footer/status/menu strip
6. more visible props/icons/details

STYLE SHIFT:
Change from minimal retro to maximalist retro arcade football.

Use:
- thicker borders
- bevels
- layered panels
- inset frames
- bright accent colors
- chunkier buttons
- decorative corners
- icon labels
- blink/pulse animations
- scanline/noise texture
- stronger sports/game presentation

GLOBAL APP SHELL:
Keep top HUD and bottom menu, but make them more crowded and more game-like.

Top HUD should include:
- title
- phase
- resource counters
- active ticker
- small alert/status chips

Bottom bar should feel like a console sports menu with large icon tabs and a denser footer strip.

Also add:
- a thin scrolling ticker line
- small decorative status text
- stronger chrome around the viewport

BACKGROUND:
Replace plain empty gradient feel.
Add layered atmosphere:
- stadium/crowd silhouettes
- pitch stripe overlays
- light beams
- subtle stars/noise/CRT effect
- dark sports-arena ambience
- decorative glows and framing elements
